# Energy-Data-Analysis
Python | Power BI | Data Analysis | Data Visualization | Energy Analysis

Indonesia Energy Analysis (2020–2024) using Python and Power BI


**1. Project Overview**

This personal portfolio project analyzes the Brazilian E-Commerce Public Dataset from Olist to explore sales performance, product performance, customer purchasing behavior, payment methods, delivery efficiency, and customer satisfaction.
The objective is to transform raw e-commerce data into meaningful business insights using SQL and interactive Power BI dashboards.

**2. Tools and Technologies**

- Python
- Pandas
- Numpy
- Matplotlib
- Seaborn
- VS Code
- Power BI
- CSV


**3. Dataset**

Source: Our World in Data (OWID) – Energy dataset.

(https://github.com/owid/energy-data)

This repository does not include the original dataset. Please download it from the source.


**4. Project Objectives**

1. Analyze Indonesia's total energy consumption and its changes over time.

2. Examine the contribution of fossil fuels to energy consumption.

3. Explore renewable energy development and its share.

4. Analyze electricity generation by energy source.

5. Examine electricity-related carbon emissions.

6. Evaluate energy efficiency and domestic energy production.
